# 🌐 Personal Portfolio Website

This repository contains the source code for my personal portfolio website.
The site is designed to present who I am, what I do, and the tools and technologies I work with, in a clean, structured, and minimal way.

---

## 📌 Overview

This website showcases:

* My professional identity and roles
* A brief personal introduction
* My technical skill set and toolbox
* My core abilities across development and data analysis

The focus of this project is **clarity, structure, and visual hierarchy**, rather than heavy animations or frameworks.

---

## 🛠️ Built With

* **HTML5** – semantic and structured markup
* **CSS3** – layout, styling, transitions, and responsiveness
* **JavaScript (Vanilla)** – typing animation for role display
* **Remix Icons** – UI icons
* **Devicon CDN** – technology logos

No frameworks or libraries are used intentionally, to keep the project lightweight and easy to understand.

---

## ✨ Key Features

* **Typing animation** for dynamic role display
* **Minimalist UI** with consistent section dividers
* **Grayscale-to-color hover effects** on skill icons
* **Card-based abilities section** for better visual separation
* **Clean typography and spacing** for readability
* **Responsive-friendly layout** (desktop-first, extensible)
